# py-comfy-nodes

ComfyUI 的自定义节点和工具集合，提供实用的节点功能和节点对齐工具。

## 功能特点

### 1. 自定义节点

#### Float to String 节点
- **分类**：py-utils
- **功能**：将浮点数转换为指定小数位数的字符串
- **输入**：
  - float_value: 要转换的浮点数（范围：-1,000,000.0 到 1,000,000.0）
  - decimal_places: 保留的小数位数（范围：0 到 10）
- **输出**：转换后的字符串

### 2. 节点对齐工具

提供直观的节点布局和对齐功能，帮助您轻松组织工作流中的节点。

#### 主要功能
- **基础对齐**：左对齐、右对齐、上对齐、下对齐、水平居中、垂直居中
- **等宽等高**：设置所选节点相同宽度或高度
- **分布排列**：水平均匀分布、垂直均匀分布
- **智能布局**：基于连接关系的智能对齐
- **树状布局**：将节点排列成树状结构
- **相邻放置**：快速将节点放置在右侧或下方
- **撤销重做**：支持对齐操作的撤销和重做
- **界面控制**：可拖拽的控制面板，支持永久显示或选择时显示

## 安装方法

1. 将 `py-comfy-nodes` 文件夹复制到 ComfyUI 的 `custom_nodes` 目录下
2. 重启 ComfyUI
3. 节点将自动加载，可在 `py-utils` 分类中找到
4. 节点对齐工具将在选择多个节点时自动显示

## 使用说明

### Float to String 节点

1. 在 ComfyUI 界面中搜索 "py-utils: Float to String" 节点
2. 连接浮点数输入和小数位数参数
3. 节点将输出格式化的字符串

### 节点对齐工具

1. 选择多个节点
2. 控制面板将自动显示（或通过右键菜单手动显示）
3. 点击相应的对齐按钮执行操作
4. 拖动控制面板调整位置
5. 使用 "Toggle Mode" 按钮切换显示模式（永久显示或选择时显示）

## 快捷键和操作

- **选择节点**：按住 Shift 键点击节点
- **移动控制面板**：拖拽面板或分隔符
- **撤销操作**：点击撤销按钮或使用快捷键
- **重做操作**：点击重做按钮或使用快捷键
- **关闭面板**：点击关闭按钮

## 配置和自定义

### 存储位置

工具的配置信息存储在浏览器的 localStorage 中，包括：
- 控制面板位置
- 显示模式设置
- 可见性状态

### 自定义样式

如果需要自定义控制面板的样式，可以修改 `js/NodeAlignConstants.js` 文件中的 CSS 样式定义。

## 开发说明

### 添加新节点

1. 在 `py_FloatToString.py` 文件中创建新的节点类（或创建新的模块文件）
2. 在 `__init__.py` 文件中注册新节点
3. 更新 `NODE_CLASS_MAPPINGS` 和 `NODE_DISPLAY_NAME_MAPPINGS`

### 自定义对齐功能

修改 `js/NodeAlign.js` 文件中的 `ALIGNMENT_CONFIG` 对象和相关方法。
